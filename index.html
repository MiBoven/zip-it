Recover password

Zip-It tries passwords against the archive, here on your device. This only has a chance for weak or partly-remembered passwords — a strong unknown password can't be recovered.

#a digit 0–9?a lowercase letter
^an uppercase letter@any letter
*letter or digit!a symbol

Everything else is taken literally. Use \\# for a real #. Example: Sommer#### tries Sommer0000 … Sommer9999.

Check against data leaks

This looks your password up in the Have I Been Pwned database, which collects passwords exposed in public data breaches. If yours appears there, attackers already have it on their lists — pick a different one.

Your password is never sent. Zip-It hashes it (SHA-1) in your browser and sends only the first 5 characters of that hash to api.pwnedpasswords.com. The server replies with all hashes starting with those 5 characters; the match is found here on your device (this is called k-anonymity). The server can't tell which one — or even whether any — was yours.

This is the one and only time Zip-It contacts a server, and only when you tap “Check”. Everything else stays on your device.

Zip-It

The Zipper for your Files

Version 0.4.0

Packs files and folders into ZIP, TAR, TAR.GZ and GZ archives — and unpacks them again. Everything happens on your device: no file ever leaves your browser, and the app works offline once loaded.

PackZIP, TAR, TAR.GZ, GZ
UnpackZIP (incl. AES & ZipCrypto), TAR, TAR.GZ / TGZ, GZ
EncryptionAES-256 (WinZip AE-2) or ZipCrypto
CompressionDeflate, levels 0 (store) – 9 (maximum)

Privacy: no tracking, no cookies, no uploads. Only your theme and default settings are stored locally in this browser.

Install Zip-It

Install Zip-It like a regular app — it then starts from your home screen and works offline.

AndroidChrome menu ⋮ → Install app / Add to Home screen
iPhone / iPadSafari Share button → Add to Home Screen
DesktopChrome / Edge: install icon in the address bar, or menu → Install Zip-It
