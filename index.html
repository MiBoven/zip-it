Recover password

Zip-It tries passwords against the archive, here on your device. This only has a chance for weak or partly-remembered passwords — a strong unknown password can't be recovered.

Resume earlier attempt?

#a digit 0–9?a lowercase letter
^an uppercase letter@any letter
*letter or digit!a symbol

Everything else is taken literally. Use \\# for a real #. Example: Sommer#### tries Sommer0000 … Sommer9999.

Check against data leaks

This looks your password up in the Have I Been Pwned database, which collects passwords exposed in public data breaches. If yours appears there, attackers already have it on their lists — pick a different one.

Your password is never sent. Zip-It hashes it (SHA-1) in your browser and sends only the first 5 characters of that hash to api.pwnedpasswords.com. The server replies with all hashes starting with those 5 characters; the match is found here on your device (this is called k-anonymity). The server can't tell which one — or even whether any — was yours.

This is the one and only time Zip-It contacts a server, and only when you tap “Check”. Everything else stays on your device.

Zip-It

The Zipper for your Files

Version 0.7.1

Packs files and folders into ZIP, TAR, TAR.GZ and GZ archives — and unpacks them again. Everything happens on your device: no file ever leaves your browser, and the app works offline once loaded.

PackZIP, TAR, TAR.GZ, GZ
UnpackZIP (incl. AES & ZipCrypto), TAR, TAR.GZ / TGZ, GZ, XZ / TAR.XZ, LZMA
EncryptionAES-256 (WinZip AE-2) or ZipCrypto
CompressionDeflate, levels 0 (store) – 9 (maximum)

Privacy: no tracking, no cookies, no uploads. Only your theme and default settings are stored locally in this browser.

Help & info

  • Pack bundles files into one archive; Unpack opens an existing one. Switch at the top.
  • Choose, drag & drop, or drop a whole folder — the folder structure is kept.
  • The installed app (menu → Install app) works offline and appears in Android's share menu, so you can share files straight to Zip-It.
  • On phones: the Files picker keeps original file names; the photo picker may not.
  • Archive name: defaults to zipped-it_[date]-[time]; the extension is added for you.
  • Format: ZIP, TAR.GZ, TAR or GZ — see “Compression & formats” below.
  • Compression: Store (0) to Maximum (9). Higher = smaller but slower, and only helps on compressible data.
  • Skip system files: leaves out OS clutter like .DS_Store and Thumbs.db.
  • Verify after packing: re-reads the finished archive to catch a bad write before you delete the originals.
  • Tick individual files and use Extract selected, or Download all / Extract to folder… (Chrome/Edge on desktop keep the folder structure).
  • Into a subfolder puts everything in a folder named after the archive, so files don't land loose in your downloads.
  • Convert / re-save turns an opened archive into another format and/or changes the password (add, change, remove). The original stays untouched.

AES-256 is strong, modern encryption. Only the right password can open the archive. It opens with 7-Zip, WinRAR, Keka, PeaZip and most Android file managers — but not with the built-in Windows Explorer or macOS Archive Utility.

ZipCrypto is the old ZIP encryption. It opens everywhere, including Windows Explorer, but is cryptographically weak and can be broken regardless of the password — use it only for low-risk files.

The strength meter estimates how hard a password is to guess (assuming one high-end graphics card) and checks it against a list of common passwords. The optional Have I Been Pwned button checks whether it appears in public breaches, sending only a short hash prefix — never the password.

Lost a password? You can't open an AES/ZipCrypto archive without it — but see Password recovery.

If you forgot a ZIP's password, Zip-It can try to find it on your device. Common passwords runs a list (optionally with variations); I remember part of it takes a pattern like Sommer#### and tries the unknown positions. This only works for weak or partly-remembered passwords — a strong unknown password stays unrecoverable.

You can Pause and resume any time. Progress is saved in this browser, tied to the archive (its name and size) — no passwords and no file contents are stored. Re-open the same archive and Zip-It offers to resume where it left off.

Clearing it: it clears automatically once the password is found or the search is exhausted, or when you choose “Start over”. To wipe all saved recovery data at once, use Settings → Clear saved recovery progress.

Packing is lossless — it finds repetition and stores it compactly without changing your data. So it shrinks some things a lot and others barely at all:

Shrinks wellText, code, CSV/JSON, logs, XML, uncompressed images (BMP), many documents
Barely shrinksJPEG/PNG/HEIC photos, MP4/MOV videos, MP3/AAC audio, PDFs, other archives — already compressed

A phone photo typically gets only ~2% smaller even with the strongest compressor — that's normal. Zip-It stores already-compressed files as-is instead of wasting time, which is why you may see “no size gain”. Making a photo smaller needs lossy re-encoding (an image tool's job), because it changes the image.

ZIPUniversal default, opens everywhere, optional password, each file compressed separately.
TAR.GZBundles everything then compresses the whole — often smaller than ZIP for many small files. No password.
TARBundles only, no compression.
GZA single compressed file (no folders).
XZ / LZMAStrong LZMA compression. Zip-It can unpack these; it doesn't create them.
  • Everything happens on your device. No file is ever uploaded, there are no accounts, no tracking and no cookies.
  • The only network request is the optional Have I Been Pwned check, and only when you tap it.
  • Stored in this browser only: your theme and default settings, and any paused recovery progress. Clear the latter in Settings.
  • Copied passwords can be auto-cleared from the clipboard a short time after “Copy password” (Settings), unless you've copied something else since.
